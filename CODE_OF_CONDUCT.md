# Code of Conduct

This project follows the spirit of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Expected behaviour

- Be respectful and technical. Critique ideas, not people.
- Assume good faith; ask for reproduction steps before judging a report.
- Keep discussions on topic and free of spam, self-promotion, or vendor bashing.

## Unacceptable behaviour

Harassment, discrimination, personal attacks, doxxing, publishing private
information, or sustained disruption of issues and pull requests.

## Enforcement

Report incidents privately to the maintainer through the GitHub profile
(https://github.com/GreenJenckens) or a private security advisory on this
repository. Reports are handled confidentially. Consequences range from a
warning to a permanent ban from the repository, at the maintainer's discretion.

This Code of Conduct applies to issues, pull requests, discussions, and any
project space where this repository is represented.
